# Security

## Reporting a problem

Please do not open a public issue for a security problem. Report it privately through GitHub:
the repository's **Security** tab › **Report a vulnerability**
([direct link](https://github.com/electronic-mars/OY/security/advisories/new)).
Only the maintainer sees the report, and the conversation stays private until a fix is out.

Useful to include: the OY Player version (Settings › About), Windows' version, and the steps or a
file that shows the problem.

## Supported versions

Fixes go into the newest release. The player updates itself from the signed releases on this
repository's Releases page; please check the problem on the newest version before reporting.
